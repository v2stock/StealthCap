## 简介

**隐捕（StealthCap）** 是一款面向个人设备所有权人的桌面屏幕操作记录与回放工具。它的目标场景是：你离开电脑后，设备可能被他人使用，你希望在事后回看这段时间内设备上发生的主要操作，而不必进行高帧率的持续录屏。

软件以后台驻留方式运行，仅在系统托盘保留一个图标；只有在你主动开启"布控"状态时，才会在检测到键盘/鼠标输入后按冷却间隔抓取屏幕画面，压缩加密后写入本地 `.scap` 记录文件。所有记录数据只保存在本机，除激活环节外全程离线，不收集、不上传任何数据。

- **技术栈**：.NET 10 + C# + WinForms，Native AOT 单文件发布（无需安装 .NET 运行时）

- **目标平台**：Windows 10 1809+ / Windows 11，x64

- **软件版本**：v1.0（2026）

## 功能特性

### 后台驻留与状态控制

| 功能         | 说明                                  |
| ---------- | ----------------------------------- |
| 无主窗口启动     | 启动后不显示任何窗口，仅驻留系统托盘                  |
| 单实例运行      | 命名互斥体（Mutex）保证同一时间只有一个实例            |
| 布控 / 休眠双状态 | 布控态响应输入并记录，休眠态完全不采集、不写盘             |
| 全局热键切换     | 默认 `Ctrl + Alt + S`，在桌面、锁屏、全屏应用下均有效 |
| 锁屏自动布控     | 监听会话切换事件，锁屏时自动进入布控（可关闭）             |
| 布控隐藏托盘图标   | 布控期间隐藏托盘图标（注册功能）                    |
| 看门狗守护      | 独立守护进程在主进程被强制结束时静默拉起，主进程正常退出时自动退出   |
| 开机自启       | 通过 `HKCU\...\Run` 实现，默认关闭           |

### 记录引擎

| 功能     | 说明                                                    |
| ------ | ----------------------------------------------------- |
| 全局输入监听 | 低级键盘/鼠标钩子（`WH_KEYBOARD_LL` / `WH_MOUSE_LL`），回调中仅做事件通知 |
| 冷却间隔   | 两次截图的最小间隔，默认 5000 ms（可配置）                             |
| 差异检测   | 对比原始像素采样，画面变化超过阈值才继续记录，避免记录静止画面                       |
| 截图范围   | 主屏幕 / 全部屏幕                                            |
| 编码与缩放  | JPEG（默认）或 WebP；支持 25%–100% 缩放（后两项为注册功能）               |
| 水印     | 可选叠加时间、用户名、本机 IP，9 个位置可选，字号可调                         |
| 文件滚动   | 按大小（默认 500 MB）、时长（24 h）、帧数（5000 帧）滚动；支持循环录像           |
| 存储上限   | 默认 30 GB，超限自动清理最旧文件（环形缓冲）                             |

### 回放与导出

| 功能     | 说明                                                       |
| ------ | -------------------------------------------------------- |
| 文件列表   | 按时间浏览本机 `.scap` 记录文件                                     |
| 缩略图时间轴 | 点击缩略图跳转对应帧                                               |
| 播放控制   | 上一帧 / 下一帧、幻灯片播放、0.5x–8x 速度调节、滚轮缩放、双击全屏                   |
| 导出 MP4 | 解密帧后经 `image2pipe` 管道直送 FFmpeg 编码，全程无明文中间文件落盘；导出前有安全确认提示 |
| 导出水印   | 所有导出内容强制加水印（时间戳 + 本机 IPv4），无法关闭                          |

### 安全与隐私

| 机制   | 说明                                              |
| ---- | ----------------------------------------------- |
| 记录加密 | 每帧 AES-256-GCM 加密，独立随机 Nonce，GCM 认证标签防篡改        |
| 密钥分层 | 主密钥由 Windows DPAPI（CurrentUser）保护，密码用于派生主密钥访问凭据 |
| 设备绑定 | 记录数据与主密钥绑定当前设备与当前 Windows 账户，拷贝到其他设备无法解密回看      |
| 密码保护 | 退出、进入设置、查看记录均需密码验证；错误 5 次锁定 5 分钟                |
| 日志加密 | 运行日志逐行独立认证加密                                    |
| 无遥测  | 除激活环节外无任何网络通信，不含更新检查、崩溃上报、遥测收集等功能               |

### 界面与体验

- 语言（简体中文 / English / 跟随系统）与主题（跟随系统 / 深色 / 深色推荐 / 浅色）即时切换，无需重启

- 全窗体高 DPI 适配（100%–300%），多显示器与 4K 环境可用

## 快速开始

### 运行环境

| 项目   | 要求                            |
| ---- | ----------------------------- |
| 操作系统 | Windows 10 1809+ / Windows 11 |
| 架构   | x64                           |
| 运行时  | 无需安装，发布包为自包含单文件               |
| 磁盘   | 按存储上限预留空间（默认 30 GB 上限）        |

### 安装与运行

1. 从 [Releases](https://github.com/v2stock/StealthCap/releases) 下载发布包并解压到任意目录（绿色版，无需安装）。
2. 确认 `StealthCap.exe` 同目录下存在 `ffmpeg.exe`（导出 MP4 功能需要，不导出视频可以不e该工具）与 `COPYING.gplv3.txt`。
3. 双击 `StealthCap.exe` 启动，程序无主窗口，仅出现托盘图标。
4. **首次运行**会依次要求：阅读并同意合规声明 → 设置主密码 → 保存一次性恢复密钥。请务必妥善保存恢复密钥，密码遗失时它是唯一的自助恢复途径。

### 默认快捷键

| 快捷键                               | 作用           |
| --------------------------------- | ------------ |
| `Ctrl + Alt + S`                  | 切换布控 / 休眠状态  |
| `Ctrl + Alt + Shift` + 鼠标左键点击托盘图标 | 呼出主界面（需密码验证） |
| `Ctrl + Alt + T`                  | 显示托盘图标       |

以上均可在设置中自定义。

### 日常使用

1. 离开座位前按 `Ctrl + Alt + S` 进入布控（或直接锁屏，由"锁屏自动布控"接管）。
2. 回到座位后再次按 `Ctrl + Alt + S` 退出布控。
3. 需要回看时，用呼出组合键打开主界面，验证密码后选择时间点浏览记录，必要时导出为 MP4。

## 版本与授权

- **未注册版**：每日布控记录时长上限 **100 分钟**（按自然日重置，跨日自动清零；系统时间被回拨时视为当日额度已用尽）。额度以 DPAPI 加密后同时写入文件与注册表，取两者中的保守值，删除单份副本无法绕过。

- **注册版**：取消每日时长限制，并解锁以下注册专属功能：

  - 布控时隐藏托盘图标

  - 截图缩放比例（25%–100%）

  - WebP 截图编码格式
